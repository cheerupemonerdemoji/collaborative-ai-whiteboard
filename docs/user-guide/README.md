# Collaborative AI Whiteboard — User Guide

A collaborative engineering workspace combining a free-form whiteboard with structured engineering records, experiment evidence, relationships, and recoverable history.

You can sketch ideas on the canvas the way you would on any whiteboard. Alongside the canvas, you can keep real engineering records — requirements, experiments, decisions, tasks, risks, and the evidence that backs them up — and link them together so the reasoning behind a design stays visible. Everything is saved automatically, and important moments can be marked and restored later.

## How the pieces fit together

```text
Whiteboard
   │
   ├── Canvas
   │    ├── Shapes
   │    ├── Text
   │    ├── Drawings
   │    └── Arrows
   │
   └── Semantic Inspector
        ├── Components
        ├── Interfaces
        ├── Requirements
        ├── Tasks
        ├── Experiments
        ├── Decisions
        ├── Risks
        └── Evidence
                 │
                 └── Structured tables

Important changes
       │
       ▼
     History
       ├── Checkpoints
       └── Restore
```

The **canvas** is for visual thinking: sketches, notes, diagrams, arrows. The **Semantic Inspector** is for structured engineering records. They live on the same whiteboard but they are different things — [Canvas Basics](canvas-basics.md) explains the difference.
